# Fourfold: исходники и экспорт

Исходные `chassis_source.glb`, `launcher_source.glb` и `wheel_source.glb` скопированы без изменений из трёх файлов пользователя. Каждый содержит один меш и не содержит скелета. `build_unit.py` размещает их в одной системе координат, создаёт SCM с отдельной костью пускового блока и восемью костями колёс, записывает материалы DDS и два игровых клипа SCA. Исходные положения точек выпуска выставлены по четырём отверстиям пускового блока. Изображение `assembled_transport_scm.png` прочитано из экспортированного SCM; оно не доказывает поведение анимаций в игре.

`UEL0213_deploy.sca` длится 3 секунды и переводит блок из походного положения в поднятое. `UEL0213_wheels.sca` задаёт один оборот колёс за время, соответствующее длине окружности при максимальной скорости 2,2. Иконка создаётся `create_icon.py` из SCM.

Не проверено в матче: точное совмещение осей, вращение и остановка колёс, блокировка выстрела на время развёртывания, положение каждого muzzle, вид снарядов, перезарядка и обратная анимация. Управляемый поворот передних колёс и боковые выдвижные опоры потребуют отдельной геометрии или переработки исходных мешей.

Дополнительно сохранён 'assembled_deployed_scm.png': расчётная поднятая поза из экспортированного SCM после поворота кости. Это не игровая проверка.
Исправлена привязка по референсу: шасси развёрнуто носом к +Z; ось пускового блока теперь поперечная, его собственный шарнир совмещён с задним креплением платформы. Обновлены SCM, SCA, положения muzzle и иконка. Прежняя сборка в archive/before-rear-hinge-fix. Проверены расчётные крайние позы, в матче не проверено.

Пусковой блок расширен поперёк до ширины платформы: 1,181 игровой единицы (примерно в 2,22 раза шире прежнего). Мuzzle-кости разнесены с тем же коэффициентом, нормали скорректированы для растяжения. Обновлены SCM, SCA и иконка; проверены крайние позы по экспортированному SCM. Предыдущая сборка в archive/before-platform-width-launcher. В игре не проверено.

Удлинённый блок с опорой на землю: корпус перестроен с четырьмя круглыми отверстиями, сечение 1,181×1,181; декоративные панели выступают на 0,0006. Ось вынесена за корму в (0; 0,95; -2,02) на двух крепёжных балках. Вертикальное основание Y=0, верх Y=3,42. В сложенной позе нижняя грань Y=0,75, передний торец Z=0,45 — у блока за кабиной. Экспортированная геометрия проверена численно и по крайним ракурсам, контакт с неровной местностью и поведение в матче не проверены. Исходная трёхмерная оболочка пускового GLB заменена простой замкнутой геометрией, прежняя сборка сохранена в archive/before-grounded-launcher.
