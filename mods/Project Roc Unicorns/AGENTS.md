# Подготовка Project Roc Unicorns к загрузке

Когда пользователь поручает подготовить новую версию мода к загрузке:

1. В рабочем `mod_info.lua` увеличь на единицу числовой суффикс `uid` после последнего дефиса и значение `version`. Например, суффикс `-8` и `version = 8` становятся `-9` и `version = 9`. Сохраняй остальную часть UID.
2. Подготовь устанавливаемую копию мода в `D:\Games\FafModsCreate_Export\Project Roc Unicorns` с обновлённым `mod_info.lua` и необходимыми игровыми файлами. Удали из экспортной копии ненужные для игры исходники, архивы, документацию, кэш и временные файлы. Перед удалением проверь зависимости: игровые файлы могут загружаться по имени или динамически. Рабочие исходники и резервные версии сохраняй. Проверь состав и соответствие оставшихся файлов рабочей версии; особенно убедись, что архивные `.bp` не попали в экспорт.
3. Подготовь изменения в репозитории, отправь ветку на GitHub и создай pull request с описанием изменений и выполненных проверок.

Не повышай версию при обычном редактировании или отдельном экспорте: эти действия относятся к подготовке новой версии к загрузке. Проверку в игре указывай только если она действительно выполнена.
