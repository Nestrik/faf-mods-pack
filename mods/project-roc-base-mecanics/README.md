# Project Roc Base Mecanics

SIM-мод для Supreme Commander: Forged Alliance в клиенте FAF. Первое изменение касается стоимости усиления щитов инженерами.

Когда инженер помогает восстановить повреждённый купол, он тратит только энергию. Расход энергии зависит от строительной мощности инженера. Мод сохраняет заданную для щита ставку энергии. Для щитов без такой ставки он берёт 75% стоимости генератора в энергии и делит на время его постройки, как при базовом расчёте ремонта в FAF.

Если повреждены одновременно купол и корпус, FAF делит строительную мощность инженера поровну. Материя расходуется только на ремонт корпуса. Правило действует для юнитов категории `SHIELD`, которым FAF разрешает помогать, и применяется к каждому помощнику.

## Требования и установка

Требуется FAF с поддержкой отдельных ставок расхода для помощи щитам, добавленных в патче 3841. Скопируйте папку `project-roc-base-mecanics` целиком в каталог `mods` данных FAF. Включите **Project Roc Base Mecanics** в списке симуляционных модов перед матчем. Для сетевой игры мод нужен всем участникам.

## Статус

Версия 2. Хук и штатная функция расчёта потребления проверены вне игры на исходниках FAF 3841. Для инженера T1 UEF со строительной мощностью 5 и генератора щита T2 UEF получены следующие значения.

| Что восстанавливает инженер | Энергия/с | Материя/с |
|---|---:|---:|
| Только купол | 19,57 | 0 |
| Купол и корпус одновременно | 19,57 | 0,98 |
| Только корпус | 19,57 | 1,96 |
| Купол и корпус полностью целы | 0 | 0 |

Проверка в матче ещё не проводилась. Для неё назначьте инженера на помощь полностью построенному генератору и сравните расход самого инженера при повреждении купола и корпуса. Генератор отдельно потребляет энергию на содержание щита.
