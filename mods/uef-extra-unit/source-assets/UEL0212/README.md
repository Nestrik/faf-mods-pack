# Cerberus UEL0212

Три исходных GLB предоставлены пользователем. `assembled_separate.blend` содержит шасси, башню и три отдельных объекта орудий; `split_guns.py` создаёт её из прежней сборки. В игровой SCM экспортированы отдельные кости наведения и отката для верхнего, левого и правого орудий. Верхний шарнир управляет нижними через CreateSlaver; точки выпуска дочерние костям отката. После каждого выстрела соответствующий ствол сдвигается внутрь и возвращается обратно.

`export_separate_guns.py` читает `mesh.json` и пишет SCM в локальную папку `game_stage`; для установки SCM копируется в `units/UEL0212`. Ракурсы `scm_separate_*` и `pose_recoil_*` отрендерены из экспортированных SCM и расчётных положений. Предыдущие модель и скрипт сохранены в `archive/before-separate-recoil-2026-11-15`.

Гусеницы не анимированы. В матче необходимо проверить синхронизацию наклона, индивидуальный откат, точки выстрела, эффекты и отсутствие пересечений с башней.
