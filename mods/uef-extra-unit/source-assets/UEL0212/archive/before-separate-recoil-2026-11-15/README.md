# Cerberus UEL0212

Три исходных GLB предоставлены пользователем. assembled.blend содержит совмещённые детали. SCM экспортирован из mesh.json с помощью export_game.py и supcom_binary.py; scm_preview.py служит для просмотра. Экспорт создаёт локальную папку units, файлы затем копируются в игровую units/UEL0212. Скрипт assemble.py использует исходные пути загрузки на этом компьютере. Ракурсы scm_*.png получены из экспортированного SCM.

Три ствола используют общий шарнир наклона; под большими углами их совмещение с отверстиями может изменяться. Гусеницы не анимированы. Игровая проверка не проведена.
