# Каталог модов

Каждый мод размещается в собственной папке: `mods/<короткий-id-мода>/`. В папке мода должны находиться его `mod_info.lua`, описание и игровые файлы.

Создавайте `mod_info.lua` непосредственно в корне папки мода. Не размещайте здесь общие игровые файлы нескольких модов.

## Моды

- [Seraphim T1 Missile Launcher](seraphim-t1-missile-launcher/README.md)
- [Seraphim Rework](seraphim-rework/README.md)
- [Seraphim Additional Units](seraphim-extra-units/README.md) — Itha-Suun GGA0402 и Itha-Vael GGA0403, независимый мод дополнительных юнитов.
